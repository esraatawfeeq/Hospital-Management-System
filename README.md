# 🏥 Hospital Management System (Python OOP)

A comprehensive, interactive, terminal-based **Hospital Management System** implemented in Python. Designed following strict Object-Oriented Programming (OOP) principles, structured data handling, input validations, and complete CRUD operations.

---

## 🚀 Key Features

* **Object-Oriented Architecture**: Implemented 12 distinct classes using core OOP concepts like **Inheritance**, **Encapsulation**, and **Polymorphism**.
* **Data Containers Strategy**:
  * **Tuples**: For fixed data structures (`ROOM_TYPES`).
  * **Sets**: For unique disease categorizations (`DISEASES_SET`).
  * **Dictionaries**: For managing structured departmental data.
  * **Lists**: For dynamic runtime storage of entities.
* **Full CRUD Operations**: Create, Read, Update, and Delete for Doctors, Patients, Nurses, Rooms, Appointments, Bills, and Staff members.
* **Robust Input Validation**: Strict checking for IDs, Age, Phone Numbers, Salaries, and Date restrictions.
* **Billing & Reporting System**: Automatic cost calculations (Consultation, Medicine, Room) and real-time statistical reports.
